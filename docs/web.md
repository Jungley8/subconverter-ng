# Web 界面

subconverter-ng 内置了一个轻量的可视化 Web 界面，已通过 `go:embed` 打包进二进制，无需任何额外服务或前端构建步骤。

## 打开

服务启动后，用浏览器访问根路径即可：

```
http://127.0.0.1:25500/
```

（端口取决于 `--listen` / `SUBNG_LISTEN`，默认 `25500`。）

## 使用

1. **订阅链接**：粘贴机场订阅地址，一行一个，多个会自动用 `|` 合并。
2. **外部配置 config**（可选）：填入 INI 规则配置的 URL（兼容 subconverter / ACL4SSR）。
3. **生成令牌**：选择到期时间并点击生成；新令牌会填入下方“访问令牌”，同时显示该令牌的实际到期时间。每次点击都会生成独立令牌。
4. **访问令牌**：也可以直接粘贴已有令牌。
5. **目标 target**：选择输出格式，受控到期替换主要用于 `clash`。
6. **选项和 proxy**：按需设置节点处理选项；受控链接不会把原始订阅、config 或 proxy 写入分享地址。
7. 点击 **生成订阅链接** 后，下方才会显示完整的 `/sub?...` 链接。
8. 点击 **复制**，把链接粘贴到 Clash / mihomo 客户端的「配置 URL」即可。

要直接创建临时受控订阅，先填写订阅地址和到期时间，再点击 **生成令牌**。每次点击都会生成一个新的 64 位随机令牌，分别绑定当时填写的订阅、config 和到期时间，并直接显示每小时刷新的可分享链接。到期后的 Clash 刷新会收到空节点配置。临时令牌保存在内存中，服务重启后失效。

## 说明

- 生成的链接以当前访问的 host 为基准（`window.location.origin`），所以无论部署在本地还是服务器上都能正常使用。
- 页面完全自包含：内联 CSS / JS，不依赖任何外部 CDN，适合中国大陆等网络环境。
- 支持深色模式（跟随系统 `prefers-color-scheme`），移动端自适应。
- **表单缓存**：订阅链接、target 与各选项会自动存入浏览器 `localStorage`，刷新或下次访问自动恢复，无需重填。数据仅保存在本地浏览器，不上传服务器；换浏览器 / 清除浏览数据即失效。
- **临时创建接口**：`POST /access/create` 当前没有管理员鉴权，只受按 IP 限流保护；公网部署时任何访问者都能创建临时令牌。
- 链接的参数含义与 [URL 参数](url-params.md) 一致。
