# Web 界面

subconverter-ng 内置了一个轻量的可视化 Web 界面，已通过 `go:embed` 打包进二进制，无需任何额外服务或前端构建步骤。

## 打开

服务启动后，用浏览器访问根路径即可：

```
http://127.0.0.1:25500/
```

（端口取决于 `--listen` / `SUBNG_LISTEN`，默认 `25500`。）

## 功能模块

界面提供 **订阅转换** 与 **我的订阅** 双轨功能：

### 1. 订阅转换 (⚡)

1. **订阅链接**：在文本框里粘贴机场订阅地址，一行一个，多个会自动用 `|` 合并；也可点击上方「从订阅库导入」快速载入已保存的订阅，或点击「存入订阅库」将当前链接收藏管理。
2. **外部配置 config**（可选）：填入 INI 规则配置的 URL（兼容 subconverter / ACL4SSR）。
3. **目标 target**：下拉选择输出格式 —— `clash`（Clash.Meta / mihomo）、`singbox`、`surge`、`shadowrocket`、`quanx`、`loon`、`v2ray`/`mixed`。
4. **选项**：按需勾选 `节点排序`、`节点去重`、`强制 UDP`、`TCP Fast Open`、`跳过证书校验`、`过滤不兼容节点`、`节点名加类型`、`Tailscale 直连`、`允许 emoji`。对应 [URL 参数](url-params.md) 里的 `sort` / `dedup` / `udp` / `tfo` / `scv` / `fdn` / `append_type` / `tailscale` / `emoji`。
5. **上游代理 proxy**（可选）：例如 `socks5://127.0.0.1:1080`，仅对本次请求生效，覆盖全局配置。
6. 点击 **生成订阅链接**，下方会显示完整的 `/sub?...` 链接。
7. 点击 **复制**，把链接粘贴到 Clash / mihomo 客户端的「配置 URL」即可；也可以点 **打开 / 预览** 在新标签页直接查看转换结果。

### 2. 我的订阅 (📋 集中管理)

为持有多个机场、自建节点或专线的用户提供本地化集中管理面板：

1. **元数据记录**（值均可选）：
   - **名称 / 备注**：如“猫熊云 - 主力”、“备用专线”。
   - **订阅或节点链接**：支持 HTTP(S) 订阅及 vless / vmess / ss 等节点链接。
   - **官网地址**：卡片直达跳转链接（`noopener noreferrer`），方便随时登录续费。
   - **到期时间**：自动计算剩余天数；7 天内临期黄色预警，已过期红色告警。
   - **流量重置日**：支持设定每月几号重置（1~31 日）或自定义重置周期说明。
   - **费用与扣费周期**：支持记录金额、币种与周期（月付、季付、半年付、年付、两年付、一次性买断等）。
   - **备忘笔记**：记录绑定的账号邮箱、套餐详情或优惠码。
2. **月均开销折算**：顶部看板根据已录入的周期与费用，自动汇总折算“月均支出”，掌握网络服务开销。
3. **一键批量转换**：卡片支持勾选状态；勾选多个订阅后，可一键批量带入转换页并生成聚合配置。
4. **数据备份与恢复**：
   - 支持下载 JSON 格式的备份文件，或复制备份文本到剪贴板。
   - 支持从 JSON 文件或剪贴板恢复，支持「追加合并（按 URL 去重）」与「完全覆盖」两种模式，防止清除浏览器缓存后数据丢失。

## 说明

- 生成的链接以当前访问的 host 为基准（`window.location.origin`），所以无论部署在本地还是服务器上都能正常使用。
- 页面完全自包含：内联 CSS / JS，不依赖任何外部 CDN，适合中国大陆等网络环境。
- 支持深色模式（跟随系统 `prefers-color-scheme`），移动端自适应。
- **本地存储与隐私**：表单配置及订阅库数据仅保存在浏览器本地 `localStorage`，不经过任何云端或服务器存储，确保敏感 Token 安全。
- 链接的参数含义与 [URL 参数](url-params.md) 一致。
